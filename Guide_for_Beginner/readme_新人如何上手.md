## 入队后要做什么
从我个人经历来看，刚拿到一台机器时是非常茫然的，一是不知道要做什么，二是不了解机械结构，三是刚入队时实际上往往都只做过一些简单的东西，而实际一个较大的项目需要的远远不止入队考核的那些，所以不知道从哪入手。我希望如果你看到这个readme能够快速入门，能够快速融入战队的日常。  
### 哨兵需要实现的功能
哨兵是一台能够全自主运动并进行目标打击的机器，哨兵相比步兵有更高的血量与更高的子弹量、更高的底盘功率，并且可以不用手动买弹，在联盟赛中，我们需要哨兵快速冲到占领点占点，同时全程以较快的速度开小陀螺（底盘高速旋转同时保持云台相对地面不动，可以正常旋转云台寻找目标进行打击），然后大云台一直匀速旋转，直到上位机识别到敌人停下，靠小云台精准定位目标的装甲板，打开摩擦轮，旋转拨弹盘将子弹打出。上面这些任务里面寻找目标和导航到目标的部分都是由视觉组的同学来做的，而你要做的是实现云台pitch、大小yaw的旋转和底盘的移动以及发射机构的控制，接收视觉导航上位机发来的数据，并执行对应控制。
**底盘移动**：接收一个设定的x、y速度，根据当前云台朝向、初始朝向、电机零位等信息，将坐标系分解到另一个方向上（哨兵是以上电时刻的云台朝向为前，其他车则以此时的云台朝向为前）（如果未进行坐标系分解，则底盘是以一个固定的方向前进，哨兵是以底盘电池方向为前，坐标系分解则是将速度转换到另一个方向上），然后再将底盘速度分解为每个电机的速度，最后再结合电机反馈报文里的速度进行PID计算，得出每个电机的电流设定值，通过CAN发送控制。全向轮底盘算是比较简单的部分。
**云台旋转**：云台分成大小云台两个部分，大云台可以360度旋转，而小云台旋转存在一定限位。云台接收目标角度数据，并结合当前角度数据（大云台yaw由外置IMU直接给出，小云台yaw、pitch由电机反馈的角度值计算得到，后续也可以看情况要不要把小云台改为IMU数据加上电机反馈角度值计算得到）PID计算得出电机的目标速度，再结合电机反馈的速度值PID计算得出目标控制值。（得看具体电机，有的电机是电压控制，有的是电流控制，有的可以直接实现速度闭环控制，如果可以直接速度闭环控制，则不用自己计算速度环PID）。底盘的控制比较简单就是因为它的控制其实不用很精确，速度和实际速度有一定差距问题不大，但云台控制不止要控制精确，还用反应迅速，不然可能就瞄不准目标了，所以这应该是最复杂的部分了。
**发射机构**：由摩擦轮与拨弹轮构成，摩擦轮负责将子弹加速，而拨弹轮负责将子弹送到摩擦轮处。摩擦轮电机需要实现快速达到稳定的高速（摩擦轮开关现在由遥控器控制，后续可以改为在上位机发现敌人，大云台停止旋转同时开启摩擦轮），拨弹盘电机也需要快速达到某个指定速度（速度要调到合适），也可以做子弹计数（不过哨兵子弹量挺多，直接泼弹也行（仅就26赛季规则而言））
**通信**：底盘和云台：通过can将大云台yaw转发给底盘；
底盘与导航上位机：通过串口，底盘给上位机裁判系统数据；上位机给底盘控制指令；
云台与自瞄上位机：通过can，云台给上位机云台角度数据；上位机给云台控制指令；
底盘与自瞄上位机：通过can转发裁判系统数据；
### 机械、硬件结构
哨兵相比步兵与英雄（死了喵）硬件与机械会复杂一些，现在很多走线如果不把整个机器拆了都看不清是怎么走的，我也只能大概描述一下（不过应该会改，并且后面应该会出现要拆整机的时候，那时候不得不了解了）。RM比赛中均采用24V电池供电。底盘采用四轴全向轮的架构，现在由底盘上的电池直接连接到分电板上再分到各个电机、控制板等（后续收到官方的裁判系统后需要将底盘电池接到裁判系统的电源管理模块上，再将电管的底盘电源输出口连接到分电板）。所有can都通过分电板连接，连接在底盘控制板[C板](https://www.robomaster.com/zh-CN/products/components/general/development-board-type-c)的can1上，底盘轮子电机采用4个[M3508](https://www.robomaster.com/zh-CN/products/components/general/M3508)（ID 0x201~0x204）。现在大云台电机电源连接在云台上，can连接在底盘上，现电机使用的是瓴控[MS9025/MF9025](http://www.lkmotor.cn/Download.aspx?ClassID=47)（ID 0x141）。底盘C板can2通过滑环连接到自瞄上位机和云台C板，底盘串口USART1通过滑环连接到导航上位机，USART6连接到裁判系统（现无裁判系统）。云台上的电源分到了两个分电板上，一个连接是所有云台结构上的电机，另一个连接的是两个上位机和云台C板、雷达（在有裁判系统之后需要将电源先连到两个继电器上，再分别连到分电板上，继电器的控制源通过滑环连接到底盘上的电源管理模块对应输出口）。自瞄上位机NX是24v直接供电，导航上位机NUC先经过一个24v-19v降压模块供电（模块上有一个开关，打开LED亮了才有供电，NUC有电的话显卡欺骗器会亮，如果要连屏幕需要拔掉欺骗器），分电板再有一路电源给到交换机，再分别给两个雷达供电，交换机同时将两个雷达数据发给NUC。云台C板can2通过分电板连接自瞄上位机与底盘C板，USART1连接外置IMU[HI12](https://www.hipnuc.com/resource_hi12.html)（注意该IMU需要5V供电，不能连USART6），can1通过另一个分电板连接到所有电机，包括两个云台角度电机[GM6020](https://www.robomaster.com/zh-CN/products/components/general/gm6020)（Pitch轴电机ID 0x209，Yaw轴电机ID 0x20A）、摩擦轮电机M3508（ID 0x201、0x202）、拨弹轮电机[M2006](https://www.robomaster.com/zh-CN/products/components/general/M2006)（ID 0x205）。遥控器连接在云台C板上，并将遥控器数据通过can2转发给底盘C板。如果后续有超电了，超电需要与裁判系统超电管理连接，再供给底盘，并与底盘C板can2连接通信。
### 要学什么
个人比较推荐中科大的RM电控教学，可以从[CAN通信](https://www.bilibili.com/video/BV1HY411D7Ar)部分开始看起，前面有用的部分大概率在考核时都已经涉及到了，如果后面用的时候发现不了解可以再回头看。3.2到3.10的部分是基础，没用过can电机进行闭环控制的话得看。然后从[底盘篇](https://www.bilibili.com/video/BV1HY411D7Ar)到[裁判系统](https://www.bilibili.com/video/BV1NNURBEE3q)这一部分看自己需要的，看完之后自己复刻一遍，在实机上跑一下。虽然现在有完整的代码，但我建议学的时候还是自己重头写一遍，可以加深自己对机械结构的理解，也会形成自己对代码风格的理解（不一定要适应我这个代码的风格，可以按自己喜欢的方式写，在后续改代码时可以更顺一点）

## 关于AI
本项目其实很少使用到agent工具，我也认为只有代码主要由自己写的才能对代码有掌控感，但我也知道，对于一个刚学编程就已经快要迈入AGI时代的人，来继承古法编程的“非遗”可能有点难度，并且完全不用AI实际也是低效且没必要的，所以讨论是否使用AI在讨论的实际上是对自己代码的掌控程度，而这种掌控能力会在ddl的时候展现，如果你AI写完一点不看在ddl时改一个东西是很慢很拖进度的。我建议是AI写完必须自己把所有写的代码都看一遍（说实话看一遍和自己写区别还是很大），尽量用AI是写一个指定功能的模块或者做重复性修改，而不是给它个目标让它AI想办法达成（比如我要解决云台控制抖动的问题，应该给提示词“gimbal_calc_rotate_pidout中增加速度闭环控制”，而不是“现在云台在xx情况下会突然剧烈抖动，怎么解决”），没必要使用像GPT-6 Astra这样的顶尖模型（至少在写这篇readme的时候还是顶尖的），不要觉得AI的能力就是自己的能力，之前就已经有个只会用AI写代码的人在集中备赛的时候被踢出队伍了。
